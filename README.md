# 今天吃什么 · 每日美食抽选机

面向中国大陆地区日常饮食场景打造的每日美食抽选网页应用，纯静态前端实现，开箱即用。

## 核心特性

- **三步点选 + 老虎机滚轮抽卡**：
  1. 选择餐段（早餐 / 午餐 / 晚餐，按当前时间自动预设）
  2. 选择就餐方式（🍳 自己做 · 单项菜谱库 / 🛵 点外卖 · 周边实店与套餐库）
  3. 选择菜系（全菜系随机 + 10 大中式与全球常见菜系）
- **自己做模式 · 本页完整图文食谱**：
  - 内置 2,980+ 道中餐与全球常见料理食谱（本地商超食材可做）
  - 抽中后直接在本页右侧展开完整食材精确用量（支持勾选备菜）、分步 SVG 图文步骤卡（支持标记完成）与火候窍门，全程无需跳转外网
- **点外卖模式 · 周边餐饮实店自动扫描与菜系归类**：
  - 自动定位或切换国内热门城市与配送范围（1km / 3km / 5km），识别周边真实餐饮门店并自动归类至 10 大菜系
  - 支持一键复制店名下单，亦支持在本地浏览器可选填个人免费高德地图 Web 服务 Key 获取更全周边门店数据

## 数据致谢

菜谱与门店数据整理自开源社区项目（HowToCook、Cook、OpenStreetMap 等），仅用于学习与日常饮食灵感参考。
